⚽ Football Prediction Bot

Telegram 足球量化预测机器人：用泊松模型结合 Elo 评分估算比赛结果概率， 对照市场赔率找出「价值偏差」，每天定时推送。

⚠️ 不构成投注建议。 市场赔率通常比简单模型更准；模型与市场差距大时，先怀疑模型。

快速开始

git clone https://github.com/modouxin-dev/football-prediction-bot.git
cd football-prediction-bot
pip install -r requirements-dev.txt
cp .env.example .env   # 填入 TELEGRAM_TOKEN 等变量
python main.py
pytest                 # 不联网，使用仿真 API 响应

部署

推荐部署到 Railway：服务连接本仓库 main 分支，构建方式为 Dockerfile。

务必挂载持久卷到 /data——预测记录、赛果回写、Elo 评分都存 在 SQLite 里，未挂载时容器重启即清零。部署后发 /status 可确认持久化是否生效。

详见仓库中的 DEPLOY.md。
