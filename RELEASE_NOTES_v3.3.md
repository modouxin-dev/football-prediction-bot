## 🚀 Getting Started

### System Requirements
```
CPU: 2+ cores
Memory: 2GB+ (4GB recommended)
Storage: 10GB+
Python: 3.10+
```

### Quick Start
```bash
# Clone repository
git clone https://github.com/modouxin-dev/football-prediction-bot.git
cd football-prediction-bot

# Install dependencies
pip install -r requirements.txt

# Run application
python main.py
```

### Docker (Recommended)
```bash
docker build -t football-bot:v3.3 .
docker run -p 5000:5000 football-bot:v3.3
```

## 🔄 Migration Guide

### From v3.0 to v3.3
1. Backup existing database
2. Stop current deployment
3. Update code to v3.3
4. Run database migration
5. Restart application
6. Verify all endpoints

**Migration Time**: < 5 minutes
**Downtime**: < 1 minute

### Rollback Procedure
```bash
# Restore previous version
git checkout v3.0
docker build -t football-bot:v3.0 .
```
